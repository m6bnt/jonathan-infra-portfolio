Infrastructure SI Hybride Sécurisée

Conception et intégration d'une infrastructure multi-sites pour l'Association of Tennis Professionals (ATP). Virtualisation VMware ESXi, pare-feux pfSense en Haute Disponibilité, PRA/PCA à Monaco, et gestion de la mobilité sécurisée.

01 / Enjeux

Contexte : Unification du SI de l'ATP

L'organisation de l'ATP rencontrait des défis majeurs dans la gestion de son SI réparti entre son siège de Londres et ses bureaux à Ponte Vedra (US), Sydney et Monaco. L'objectif de ce projet MSPR était de centraliser les ressources critiques, d'assurer une haute disponibilité et de garantir un accès sécurisé aux nombreux salariés nomades.

  • Virtualisation : Déploiement d'un hyperviseur VMware ESXi (Type 1) hébergeant l'ensemble des machines virtuelles du projet.
  • Interconnexion : Création de tunnels VPN IPsec pour relier l'ensemble des sites de manière sécurisée.
  • Continuité d'activité : Conception d'un Plan de Reprise d'Activité (PRA) complet hébergé sur le site de Monaco.
  • Mobilité : Implémentation d'accès distants (OpenVPN) et de bureaux virtuels (RDS) pour les collaborateurs en déplacement.
02 / Topologie

Architecture globale multi-sites

L'infrastructure repose sur 5 sites logiques interconnectés. Chaque site dispose de son propre adressage IP (LAN, WAN, SYNC pour la haute disponibilité, et PRA pour Monaco). Le Datacenter centralise les échanges de fichiers.

03 / Sécurité

Réseau, Pare-feux & Haute Disponibilité

La sécurité périmétrique de chaque site est assurée par une solution pfSense. Pour garantir une résilience totale, un cluster de pare-feux (Master / Backup) a été mis en place sur les sites critiques.

  • Cluster Haute Disponibilité (HA) : Utilisation du protocole CARP pour le partage d'une adresse IP virtuelle (VIP) entre les firewalls Master et Backup.
  • Synchronisation : Configuration d'interfaces dédiées (SYNC) avec pfSync pour maintenir l'état des connexions en cas de bascule.
  • Filtrage LAN/WAN : Mise en place de règles de filtrage strictes pour maîtriser les flux entre les différents VLANs et le Datacenter.

04 / Services

Active Directory, NAS & Mobilité

Pour répondre aux besoins métiers de l'ATP, nous avons déployé un ensemble de services Windows et Linux, en veillant toujours à la redondance de l'information.

  • Active Directory Multisite : Contrôleur de domaine principal à Londres (VM-UK), secondaire à Ponte Vedra (VM-US) et serveur de secours à Monaco (PRA).
  • Stockage Nextcloud : Hébergé dans le Datacenter, il permet le partage et la synchronisation sécurisée des fichiers. L'accès s'effectue via une interface web ou des clients lourds.
  • Bureaux Virtuels (RDS) : Les collaborateurs nomades s'authentifient sur le VPN (OpenVPN) puis accèdent à une VM-RDS-UK via le protocole RDP pour travailler de manière centralisée.

05 / Continuité

Supervision Zabbix & Plan de Reprise d'Activité

L'anticipation des pannes est au cœur de ce projet. Outre la redondance des pare-feux et des serveurs AD, un PRA complet a été documenté et scripté pour le site de Monaco.

  • Monitoring Zabbix : Installation d'un serveur Zabbix à Londres. Remontée des alertes via des agents déployés sur les machines critiques (CPU, RAM, Disque, Statut réseau).
  • Sauvegarde automatisée : Création d'un script `Robocopy` planifié via le planificateur de tâches Windows, qui copie les données critiques de Londres vers le NAS de Monaco tous les jours à 22h.
  • Bascule (Failover) : En cas de chute du site londonien, les utilisateurs sont redirigés vers le serveur VM-RDS-MONACO disposant des dernières données synchronisées.

06 / Perspectives

Stratégie Cloud & Modernisation (UCaaS)

En conclusion du projet, nous avons proposé au bureau exécutif de l'ATP une feuille de route pour externaliser l'infrastructure vers le Cloud à moyen terme.

  • Migration vers Microsoft Azure : Choix justifié par la fiabilité (SLA 99.9%), la sécurité (ISO 27001) et l'intégration native avec l'écosystème Windows existant.
  • Communication Unifiée (UCaaS) : Recommandation de Microsoft Teams pour centraliser la téléphonie IP, la messagerie et les visioconférences des salariés nomades.
  • Authentification SSO : Intégration de Microsoft Entra ID pour sécuriser les accès distants via l'authentification multifactorielle (MFA) et faciliter l'expérience utilisateur (Single Sign-On).
